# DJ-ROOFRAT Keyboard Reference

## Introduction

This is the complete keyboard reference for DJ-ROOFRAT, a terminal DJ simulator with dual decks, live mixing controls, and career progression. Use the **Quick-Start Cheat Sheet** below to learn the essential commands, or consult the full tables for advanced controls.

---

## Quick-Start Cheat Sheet

| Key | Action |
|-----|--------|
| `A` | Play/Pause Deck A |
| `B` | Play/Pause Deck B |
| `Z`/`X` | Nudge Deck A Tempo Up/Down |
| `I`/`K` | Nudge Deck B Tempo Up/Down |
| `\` | Crossfade Center |
| `S` | Toggle Recording |
| `Shift+V` | Save Recording |
| `Q` to `Y` | EQ Controls Deck A (Low/Mid/High/Filter) |
| `D` to `,` | EQ Controls Deck B (Low/Mid/High/Filter) |
| Type `quit` or `exit` | Quit Application |

---

## Deck A — Basic Controls

| Key | Command |
|-----|---------|
| `A` | Play/Pause Deck A |
| `Z` | Nudge Tempo A Up (+) |
| `X` | Nudge Tempo A Down (−) |
| `C` | Reset Tempo A |

## Deck B — Basic Controls

| Key | Command |
|-----|---------|
| `B` | Play/Pause Deck B |
| `I` | Nudge Tempo B Up (+) |
| `K` | Nudge Tempo B Down (−) |
| `O` | Reset Tempo B |

---

## Crossfader

| Key | Command |
|-----|---------|
| `\` | Crossfade Center |
| Text: `xf left` | Crossfade Left (Deck A) |
| Text: `xf right` | Crossfade Right (Deck B) |

## Isolators (Shift+key)

| Key | Command |
|-----|---------|
| `Shift+Q` | Isolate Low A (kill/restore low band Deck A) |
| `Shift+W` | Isolate Mid A |
| `Shift+T` | Isolate High A |
| `Shift+F` | Isolate Mid B |
| `Shift+G` | Isolate High B |
| `Shift+U` or `Shift+P` | Toggle Filter Order |

## Loops

| Key | Command |
|-----|---------|
| `L` | Toggle Loop Deck B |

## Beat Jump — Deck A

| Key | Command |
|-----|---------|
| `[` | Beat Jump −4 Beats |
| `]` | Beat Jump +4 Beats |
| `<` | Beat Jump +1 Beat |
| `>` | Beat Jump +8 Beats |

## Beat Jump — Deck B

| Key | Command |
|-----|---------|
| `;` | Beat Jump −4 Beats |
| `'` | Beat Jump +4 Beats |

---

## Sync & Phase Alignment

| Key | Command |
|-----|---------|
| `Shift+S` | Toggle Sync Lock Deck A |
| `Shift+D` | Toggle Sync Lock Deck B |
| `-` | Nudge Beat Grid Left (−10 ms) |
| `=` | Nudge Beat Grid Right (+10 ms) |
| `Shift+−` | Adjust First Beat −10 ms |
| `Shift+=` | Adjust First Beat +10 ms |

|-----|---------|

## Text Commands

| Text Command | Action |
|-----|---------|
| `playa` / `a play` | Play Deck A |
| `playb` / `b play` | Play Deck B |
| `pausea` / `a pause` | Pause Deck A |
| `pauseb` / `b pause` | Pause Deck B |
| `togglea` / `a toggle` | Toggle Deck A |
| `toggleb` / `b toggle` | Toggle Deck B |
| `xf left` / `crossfade left` | Crossfade Left |
| `xf right` / `crossfade right` | Crossfade Right |
| `xf center` / `crossfade center` | Crossfade Center |
| `tempo up` / `nudge up` | Tempo B Up |
| `tempo down` / `nudge down` | Tempo B Down |
| `tempo reset` | Reset Tempo B |
| `loop a` | Toggle Loop Deck A |
| `loop b` / `toggle loop` | Toggle Loop Deck B |
| `cue a set` / `cue a jump` | Cue A |
| `cue b set` / `set cue` | Set Cue B |
| `cue b jump` / `jump cue` | Jump Cue B |
| `cue a1 set` through `cue b3 jump` | Multi-cue bank commands (1–3 for A, 4–6 for B) |
| `tempo ramp toggle` | Start/stop tempo ramp |
| `save recording` / `record save` | Save recording |
| `set recording filename` | Set output filename |
| `quit` / `exit` | Quit |
